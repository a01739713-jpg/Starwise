# Guion del pitch y demo de 2 minutos · STARWISE

## Pitch (5 diapositivas sugeridas)
1. **Problema:** universitarios de negocios llegan a prácticas o a su primer empleo sin haber resuelto un caso con datos reales de principio a fin.
2. **Propuesta:** STARWISE, un juego narrativo por episodios: Explorar → Practicar → Demostrar → Próximo paso. Mascota: Chispa.
3. **Cómo se mide:** microcaso A (sin ayuda) → práctica con Carmen, datos y presupuesto (con tutor) → microcaso B (sin ayuda). Se reporta *cambio observado*, no causalidad.
4. **Datos honestos:** caso 100 % sintético; del repositorio oficial solo se muestran indicadores verificados por etiqueta exacta (p. ej., 30.4 % sin prestaciones en el primer empleo, ENE 2025 UVM, encuesta no probabilística).
5. **Modelo (hipótesis):** licencia institucional por cohorte; precio NO validado; sin empresas aliadas todavía. Próximo paso: pruebas con personas externas y evidencia JSON.
